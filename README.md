# Spouzy

Thoughtful support for relationships, wellbeing and safer workplaces.

## Getting started

```sh
npm install
npm run dev
```

## Technology

- [TanStack Start](https://tanstack.com/start) — Full-stack React framework with SSR
- [Tailwind CSS](https://tailwindcss.com) — Utility-first CSS
- [Vite](https://vitejs.dev) — Dev server and bundler

## Project structure

| Path | Purpose |
|------|---------|
| `src/routes/` | TanStack Start file-based routes |
| `src/components/` | Shared React components |
| `src/lib/` | Utilities, content data and helpers |
| `src/assets/` | Editorial images |
| `public/` | Static files (logo, favicon, robots.txt) |
